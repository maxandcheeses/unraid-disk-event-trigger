#### Disk Event Trigger

Monitors array/cache disk temperatures and/or used space percentage, and
fires a Tasmota HTTP/MQTT (TLS supported) switch or a generic HTTP/HTTPS
webhook when configurable thresholds are crossed, with hysteresis, an
optional force-resend, and device-state verification - also triggers during
a parity check or array rebuild. Settings under Settings → Disk Event
Trigger.

**GitHub:** https://github.com/maxandcheeses/unraid-disk-event-trigger
